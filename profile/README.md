# mandate-spec has moved

The specification formerly published as **mandate-spec** is now the
**Home-Mandate Specification**. All repositories moved to
[github.com/home-mandate](https://github.com/home-mandate):

| Before | Now |
|---|---|
| `mandate-spec/mandate-spec` | [home-mandate/spec](https://github.com/home-mandate/spec) |
| `mandate-spec/mandate-spec-ts` | [home-mandate/spec-ts](https://github.com/home-mandate/spec-ts) |
| `mandate-spec/mandate-spec.org` | [home-mandate/home-mandate.org](https://github.com/home-mandate/home-mandate.org) |

- Website: [home-mandate.org](https://home-mandate.org)
- Go module: `github.com/home-mandate/spec` (the old releases of
  `github.com/mandate-spec/mandate-spec`, up to v0.2.0-alpha.5, remain in the Go module proxy)
- Type identifiers: `https://home-mandate.org/…` instead of `https://mandate-spec.org/…`

This organization is kept empty so that the old name is not taken by anyone else.
